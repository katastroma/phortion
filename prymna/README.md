# Prymna

Helm chart that deploys the GitOps engine for
[katastroma](https://github.com/katastroma).

Deploys implementations of
[naukleros](https://github.com/katastroma/naukleros),
[keleustes](https://github.com/katastroma/keleustes), orderer, and
[katartismos](https://github.com/katastroma/katartismos).
