# Prymna

Helm chart that deploys the pipeline stack for
[katastroma](https://github.com/katastroma).

Deploys [pharos](https://github.com/katastroma/pharos), OTel collector, source
handler APIs,
[keleustes](https://github.com/katastroma/keleustes) implementations,
[diataxis](https://github.com/katastroma/diataxis) implementations, and
[katartismos](https://github.com/katastroma/katartismos) implementations.
